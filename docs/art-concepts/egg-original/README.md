# Original egg / medallion layers

These source layers preserve the original Fleet egg/medallion design from before
the captured-fighter redesign. Render `hull.svg` first and `fleet.svg` above it,
with matching bounds.

Gameplay reuses this approved design for rare rapid-fire carriers labeled
`FIRE x2`. Runtime copies are
[`egg-hull.svg`](../../../game/assets/enemies/egg-hull.svg) and
[`egg-core.svg`](../../../game/assets/enemies/egg-core.svg). Fighter-reward
containment ships continue to use the A3 captive fighter and clamps. See the
[player manual](../../MANUAL.md#playing) for carrier and POW pickup behavior.
